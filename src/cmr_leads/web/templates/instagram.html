Falta conectar la API de Instagram

Pendiente

Completá estos datos en el .env y reiniciá el programa.

  1. La cuenta de Instagram de CMR tiene que ser profesional y estar vinculada a una página de Facebook.
  2. En developers.facebook.com creá una app (tipo Empresa) con el producto Instagram.
  3. Permisos: instagram_basic, instagram_manage_insights, pages_show_list, pages_read_engagement y, para leer mensajes, instagram_manage_messages y pages_messaging.
  4. Generá un token de usuario del sistema y completá: 
    META_ACCESS_TOKEN=...
INSTAGRAM_BUSINESS_ACCOUNT_ID=...
FACEBOOK_PAGE_ID=...   (solo para leer mensajes)
